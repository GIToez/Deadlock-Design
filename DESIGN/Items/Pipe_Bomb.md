# "Pipe Bomb"

> Transcribed from [`Deadlock Weapons and Items.docx`](../Deadlock%20Weapons%20and%20Items.docx),
> uploaded 2026-08-13. Category: Consumables Set (Throwables).

## Description

An improvised explosive packed with nails and ball bearings. High burst damage, loud, and
dangerous.

## Effects

| Field | Value |
|---|---|
| Damage | 120 (AoE) |
| Throw Range | 125 px |
| Radius | 130 px |
| Use Time | 1.0s |
| Noise lvl | 55 |
| Special | Shrapnel has extended damage falloff |

## Story Placement

Not yet placed in any scripted content. Like the Molotov Cocktail, this is a generic improvised
explosive that could plausibly turn up in any future district — left open for whoever writes the
next chapter. Its "nails and ball bearings" construction suggests a workshop/garage/industrial
source if a specific pickup location is ever needed (e.g. the Police Station's Municipal Garage
already established in Chapter 2, or the Refinery district once written) — noted as a possibility,
not a decision.
