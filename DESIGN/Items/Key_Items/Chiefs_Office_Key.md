## Description

A key given to Jim by Sergeant Ruth Calloway (department protocol — the desk sergeant holds it).
Opens the Chief's Office.

## Story Placement

**Police Station** (Chapter 2) — from Sergeant Calloway (or her body, if she's already turned);
opens the Chief's Office, where the [Old Station Skeleton Key](Old_Station_Skeleton_Key.md) is
found. See [`Locations/Police_Station.md`](../../Locations/Police_Station.md) → "Key Items."
