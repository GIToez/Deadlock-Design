# Consumables

Health, ammo, and throwables — stackable/countable items, not tied to a single narrative instance.
See [`../README.md`](../README.md) for the overall Items convention and concept-art rules.

## Current files

**Healing:**

- [`Medkit.md`](Medkit.md) — the game's standardized healing item; found throughout the Ravenwood
  Hotel and Police Station. Has a real in-game sprite (`spr_medkit.png`).
- [`Small_Medkit.md`](Small_Medkit.md) — a visually distinct smaller healing item, uploaded but not
  yet placed or distinguished mechanically from the standard Medkit — open design gap, see the
  file itself. Has a real in-game sprite (`spr_smallMedKit.png`).
